# Fotothek – Europa Bucket List 2027

Dieser Ordner sammelt **vom Nutzer gefundene Bildvorschläge**, keine automatisch freigegebenen Bilder.

## Ablauf
1. Gefundene Fotos oder Links je Reiseziel unter `vorschlaege/` sammeln.
2. Originalquelle, Urheber, Lizenz, kommerzielle Nutzbarkeit, erforderliche Namensnennung und etwaige weitere Rechte prüfen.
3. Ergebnis und Prüfdatum im jeweiligen Register dokumentieren: **offen**, **freigegeben** oder **nicht verwenden**.
4. Erst nach dokumentierter Rechteprüfung **und** gestalterischer Freigabe durch den Nutzer ins Reisemagazin übernehmen.

Ein Upload, ein Google-/Pinterest-Fund oder ein Commons-Link allein ist **keine Nutzungserlaubnis**. Ohne geklärte Rechte kein Einsatz. Keine abgelehnten Motive erneut einbauen.
